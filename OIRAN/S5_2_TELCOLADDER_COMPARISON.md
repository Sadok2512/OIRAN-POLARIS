# S5.2 TelcoLadder Comparison

The retained research baseline is TelcoLadder 0.1.0 under Apache-2.0. No newer PolyForm/noncommercial source was downloaded or imported.

TelcoLadder remains a secondary reference. Its exported model does not expose a stable field-by-field NAS security envelope contract comparable to OIRAN event schema 1.4.0. Message grouping, SBI visibility and session granularity differ, so aggregate count equality is `NOT_COMPARABLE`.

Chronology remains consistent at shared packet references. OIRAN adds explicit NGAP parent links, protected/ciphered classification and evidence-based incomplete procedures. No TelcoLadder output was treated as proof of a PDU session.
