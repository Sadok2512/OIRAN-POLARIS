- Branch base: `d3d92eae3d6883dba0d66aa9f0fc26ea3be1a5d2`.
- Working tree was clean before S4.1.

## Observed assumptions

| Layer | Evidence | Required correction |
|---|---|---|
| `session-engine` | `reconstruct()` selects the first PDU setup anchor and returns one `Reconstruction` | Add deterministic discovery returning many UE contexts and PDU sessions |
| `session-engine` model | `UeContext` contains one `pdu_session_id` | Separate UE context, PDU session, procedure, PFCP session and tunnel entities |
| `correlation-engine` | One reconstruction plus one certified scenario manifest | Add per-session evidence inputs; reject ambiguous candidates |
| API state | One `flow: CallFlow` and one canonical JSON path | Store indexed datasets and a map of independently addressable call flows |
| API sessions | `vec![session_summary(flow)]`, literal `UE-A` | Derive all summaries from indexed flows/metadata |
| React | Default route ID `5g-UE-A-pdu-1` | Require or select an API-returned session ID |
| Correlation Studio | Metric `Certified sessions = 1`; global edge query | Fetch dataset/UE/session choices and session-scoped evidence |
| Session Explorer | Text states “One certified session”; missing PDU/duration columns | Render arbitrary paginated results and full requested columns |
