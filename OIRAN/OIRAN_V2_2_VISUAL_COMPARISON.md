# OIRAN V2.2 Visual Review

The previous event-card presentation was replaced by a telecom sequence diagram: dynamic lifelines, thin directional arrows, compact labels above each path and procedure bands. N2, N4 and N3 retain distinct restrained colors; GTP-U is explicitly presented as data flow. Unknown direction is visible rather than inferred.

At 1440×900 and 1920×1080, both themes were reviewed for overflow, clipping, table density, panel alignment and sticky inspector behavior. The three-panel layout remains usable at both target sizes and uses available horizontal space. URL-backed selection survives refresh and browser history.

Evidence is stored in `OIRAN_V2_2_UI_SCREENSHOTS/`, including:

- Session Explorer in Light and Dark themes.
- Directional Call Flow in Light and Dark themes.
- Selected message with inspector.
- Zero-session capture state.
- N4 multi-interface filter.

No generated concept image was used; every image is a browser screenshot of the candidate application using real OIRAN data.
