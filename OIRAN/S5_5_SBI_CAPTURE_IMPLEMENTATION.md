# SBI Capture Implementation

`InterfaceId::Sbi` is a compile-time allowlisted target for the verified host bridge `br-oiran-sbi`. The native AF_PACKET path applies a fixed Ethernet/IPv4/IPv6 TCP/7777 predicate before storage. No HTTP client can supply a device, output path, shell command or BPF expression. Tests prove SBI acceptance and rejection of unrelated TCP/443 traffic.
