# Applications

This directory contains independently buildable and deployable user-facing
applications. Only responsibility placeholders are initialized at this stage.

- [`simulator-control/`](simulator-control/) — simulator and traffic control UI.
- [`probe-manager/`](probe-manager/) — probe and capture management UI.
- [`oiran-analyzer/`](oiran-analyzer/) — analysis, sessions, and Call Flow UI.
- [`portal/`](portal/) — application launcher only.

No existing production source has been migrated into these directories.
